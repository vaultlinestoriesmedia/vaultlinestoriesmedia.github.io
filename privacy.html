Privacy policy

Vaultline Stories operates a private production app for its own documentary channel. It uses YouTube API Services.

Google data and why we use it

When the authorized channel operator connects the app, Vaultline uses the channel ID, video IDs, titles and other release metadata, visibility, scheduling and processing status, and channel-authorized YouTube Analytics. Analytics can include views, watch time, retention, subscribers and traffic sources where available. The app uses this data for channel identity checks, approved uploads, scheduling, release verification, reporting and editorial evaluation. The public website has no sign-in form, analytics script or embedded video player.

Storage and access

The studio stores OAuth credentials as protected GitHub Actions secrets. Private GitHub records and artifacts hold production receipts and analytics for studio operations. Current analytics artifacts are configured to expire after 30 days. GitHub processes this data as the studio's infrastructure provider. The studio does not sell Google user data or use it for ad targeting. Vaultline's use of Google API data follows the Google API Services User Data Policy, including its Limited Use requirements. See also the Google Privacy Policy.

Revoke access or request deletion

The channel operator can revoke access in Google Account permissions. To request deletion of data held by Vaultline or ask a privacy question, email vaultlinestories.media@gmail.com. Deleting Vaultline's copies does not delete anything on YouTube. Use YouTube Studio for videos or data stored by YouTube.
